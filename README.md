# Burundi Cassava Leaf Disease Detection

This repository contains code and assets for detecting diseases on cassava leaves from images. It includes data preparation scripts, a Python-based processing/train pipeline, and a Flutter mobile app to run inference on-device.

Repository layout (important folders)
- `configs/` — configuration files used by training / preprocessing.
- `datasets/` — raw and processed dataset folders (generated by scripts).
- `mobile/` — Flutter mobile application (Android / iOS) that runs inference.
- `scripts/` — data download and preparation scripts (Python).
- `src/` — training and model code.

Quick setup (dev machine)

1. Python environment (for data and model work)

   - Create and activate a virtual environment (recommended):
     ```powershell
     python -m venv .venv
     .\.venv\Scripts\Activate.ps1
     ```

   - Install Python dependencies (if present):
     ```powershell
     pip install -r requirements.txt
     ```

   - Prepare or download datasets:
     ```powershell
     python scripts/download_dataset.py
     python scripts/prepare_data.py
     ```

2. Flutter / Mobile (to build and run the mobile app)

   - Install Flutter SDK (see https://flutter.dev/docs/get-started/install)
   - Install JDK 11 (or the JDK version configured in `mobile/android/gradle.properties`).
   - Ensure `JAVA_HOME` points to the JDK and `flutter` is on PATH. Verify with:
     ```powershell
     flutter --version
     java -version
     flutter doctor
     ```

   - From the `mobile/` folder:
     ```powershell
     flutter pub get
     flutter run -d <device-id>
     ```

Notes & known issues
- The Android project has been adjusted to resolve JVM target mismatches (Kotlin/Java). If you hit build errors related to Gradle/AGP/Kotlin versions, run `flutter doctor` and follow its recommendations.
- Some plugins require `compileSdk = 37` (this repo sets that in `mobile/android/app/build.gradle.kts`). If a plugin requires a higher SDK, update `compileSdk` and install the matching Android SDK platform.
- If you encounter OneDrive or permission issues when preparing data, move the project outside OneDrive or run PowerShell as Administrator.
